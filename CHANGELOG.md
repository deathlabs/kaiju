# Changelog

## [0.1.0] - 2026-11-13
### Added
- Added application record counts to backend version 0.1.0. The backend remains at version 0.1.0 from version 0.1.0.
- Added objective and reference creation and attachment during exercise updates, validated both relationships, and included searchable exercise summaries in backend version 0.1.0. The backend remains at version 0.1.0 from version 0.1.0.
- Added frontend version 0.1.0 as a new component with no previous version.
- Added Deathlabs-prefixed layout, navigation with purpose-specific icons, classification, and theme components to frontend version 0.1.0. The frontend remains at version 0.1.0.
- Added Exercises, Objectives, and References placeholder pages to frontend version 0.1.0. The frontend remains at version 0.1.0 from version 0.1.0.
- Added objective management and exercise objective and reference selection with consistent dropdown creation forms, required-field guidance, and action placement to frontend version 0.1.0. The frontend remains at version 0.1.0 from version 0.1.0.
- Added reference create, list, edit, and delete functions to frontend version 0.1.0. The frontend remains at version 0.1.0 from version 0.1.0.
- Added exercise search across titles, scenarios, authors, and related records, plus type, objective, and reference filters to frontend version 0.1.0. The frontend remains at version 0.1.0 from version 0.1.0.
- Added a current-user display and logout action to frontend version 0.1.0. The frontend remains at version 0.1.0 from version 0.1.0.
- Added validated OIDC bearer authentication and signed local development tokens to backend version 0.1.0. The backend remains at version 0.1.0 from version 0.1.0.

### Changed
- Updated frontend version 0.1.0 to use the new dark theme palette, accent color, text-style cancel actions, consistent delete controls, a streamlined exercise form, and borderless navigation with smooth labels and evenly padded icons. The frontend remains at version 0.1.0 from version 0.1.0.
- Replaced the Dashboard page with a Metrics card in frontend version 0.1.0. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated frontend version 0.1.0 to use the `DESIGN.md` tokens and a theme switcher that resets to dark mode after reload. The frontend remains at version 0.1.0 from version 0.1.0.
- Moved backend and frontend version 0.1.0 source code into component-specific `kaiju` directories. Both components remain at version 0.1.0.
- Made the Django management script executable in backend version 0.1.0. The backend remains at version 0.1.0 from version 0.1.0.
- Moved the frontend build files into its `kaiju` directory and added frontend VEX support. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated frontend version 0.1.0 to use configurable build images and a non-root Nginx runtime. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated frontend version 0.1.0 to require zlib 1.4-r0 or later. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated all frontend user-menu links to open the Kaiju GitHub repository. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated frontend version 0.1.0 to use an explicit non-root security context and writable Nginx runtime volumes. The frontend remains at version 0.1.0 from version 0.1.0.
