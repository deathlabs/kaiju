# Changelog

## [0.1.0] - 2026-11-13
### Added
- Added frontend version 0.1.0 as a new component with no previous version.
- Added Deathlabs-prefixed layout, navigation, classification, and theme components to frontend version 0.1.0. The frontend remains at version 0.1.0.
- Added Exercises, Objectives, and References placeholder pages to frontend version 0.1.0. The frontend remains at version 0.1.0 from version 0.1.0.
- Added reference create, list, edit, and delete functions to frontend version 0.1.0. The frontend remains at version 0.1.0 from version 0.1.0.

### Changed
- Moved backend and frontend version 0.1.0 source code into component-specific `kaiju` directories. Both components remain at version 0.1.0.
- Made the Django management script executable in backend version 0.1.0. The backend remains at version 0.1.0 from version 0.1.0.
- Moved the frontend build files into its `kaiju` directory and added frontend VEX support. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated frontend version 0.1.0 to use configurable build images and a non-root Nginx runtime. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated frontend version 0.1.0 to require zlib 1.4-r0 or later. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated all frontend user-menu links to open the Kaiju GitHub repository. The frontend remains at version 0.1.0 from version 0.1.0.
- Updated frontend version 0.1.0 to use an explicit non-root security context and writable Nginx runtime volumes. The frontend remains at version 0.1.0 from version 0.1.0.
