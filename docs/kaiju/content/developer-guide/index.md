# Developer Guide

These guides are for developers who want to configure, run, change, and document Kaiju. Run all Make targets from the repository root.

## First Contribution

**Step 1.** Follow the [Local Setup](local-setup.md) guide.

**Step 2.** Review the available automation in the repository `Makefile`.

**Step 3.** Make and validate your change.

**Step 4.** Preview documentation changes with the [Documentation](documentation.md) guide.

## Contributor Guides

* [Local Setup](local-setup.md): Configure and start the application locally.
* [Documentation](documentation.md): Preview and extend this documentation site.
