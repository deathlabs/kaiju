# Exercises

Kaiju organizes a tabletop exercise around its scenario, objectives, participants, events, and injects. Facilitators can also record participant responses and findings for sustainment or improvement.

## Exercise Lifecycle

An exercise moves through the following states:

**Step 1.** Planned

**Step 2.** Prepared

**Step 3.** In progress

**Step 4.** Completed

## Event Name

Each event has an Event Name. Enter it when you add or edit an event.

## Exercise Timeline

The exercise timeline shows a tab for each event in the feed panel. Select an event tab to show its injects in the feed.

Select a sender or recipient role on an inject card to see its assigned participants.

Future event tabs are disabled until all injects in the preceding events are released and resolved.

An event is upcoming until a facilitator releases an inject. It is in progress after an inject is released. When all injects are released and resolved, the event is complete. An event with no injects remains upcoming.

After a facilitator releases an inject, select **Mark resolved** when the expected response is complete.
